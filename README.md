# İsmet Işık Efekt Kartı (İsmet Light Effect Card)

Home Assistant için ışık efektleri kartı ve yönetim paneli. Entegrasyon: `ismet_light_effects`, kart: `custom:ismet-light-effect-card`.

**Lemur Light Effect Card'dan geçiş:** Eski kartta *Ayarlar → Yedek → Yedeği indir* de, burada *Yedekten geri yükle* ile yükle. Odalar, efektler ve ayarlar taşınır.

**Based on Lemur Light Effect Card by mendeburlemur — https://github.com/mendebur-lemur/lemur-light-effect-card**
